## Troubleshooting

### Issue: 404 Error when accessing `/reports/`
**Solution**: Restart the backend server to pick up route changes

### Issue: 404 Error when downloading reports
**Possible causes**:
1. The report files don't exist in the `reports/` directory
2. The file path in the database doesn't match the actual file location

**Solution**: 
- Check if files exist: `ls FORESYTE_Backend/reports/`
- If missing, the download endpoint will return a helpful error message

### Issue: Reports not showing up
**Solution**: 
- Make sure you're logged in as an investigator
- Check browser console for API errors
- Verify backend is running and accessible

## API Endpoints

- **GET `/reports`** - List all reports (with pagination)
- **GET `/reports/{report_id}`** - Get specific report details
- **GET `/reports/{report_id}/download`** - Download report file
- **POST `/reports/incidents`** - Generate new incident report
- **POST `/reports/exams/{exam_id}`** - Generate new exam report
